# HyperFlow

One-dimensional variable-area compressible duct flow with optional finite-rate chemistry (Cantera).

## Versions

- [HyperFlow_V1](HyperFlow_V1/): the original solver, examples, tools, and documentation.

## Build and run V1

Run the build and example commands from the V1 directory:

```bash
cd HyperFlow_V1
make
./HyperFlow examples/sod_shock
```

See the [V1 README](HyperFlow_V1/README.md) for dependencies and usage, and the [technical notes](HyperFlow_V1/docs/TechnicalNotes.md) for theory and verification.
