# HyperFlow

HyperFlow provides unsteady compressible reacting-flow solvers for one- and two-dimensional configurations.

- [V3](HyperFlow_V3/): two-dimensional reacting Euler equations, NND/HLLC fluxes, Strang-split CVODE chemistry and block-structured AMR. Includes planar and oblique detonation comparisons.
- [V2](HyperFlow_V2/): coupled implicit integration, fuel injection, mixing, wall friction and local heating. Includes a Ma = 4 DME heat-source example.
- [V1](HyperFlow_V1/): original solver and documentation.
